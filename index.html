What changed

The trainer now has three modes. Real global clips tries to load audio and transcripts from the open GLOBE V2 dataset. Aviation-style scripts gives focused readback practice using scripted messages. Local clip pack lets you add your own recorded or generated audio files later.

Add a local clip pack

Paste manifest JSON

Use this when you have real MP3/WAV files in the repo, for example audio/indian/001.mp3. Paste an array of clip objects, then choose “Local clip pack”.

Recommended JSON shape

[{
  "id": "ie-001",
  "accent": "Irish English",
  "type": "exact",
  "audio": "audio/irish/001.mp3",
  "transcript": "Have you ever heard the national anthem of South Korea?",
  "answers": { "task": "Exact words" },
  "spanishHint": "Escribe la frase completa."
}]

This keeps the site static and GitHub Pages-compatible. No backend and no API key are needed.

How to use it

1. Real accents

Start with GLOBE clips. Hide the transcript. Listen once. Type what he hears. Reveal and compare.

2. Aviation-style data

Switch to scripted drills. Score only the important data: callsign, altitude, runway, heading, frequency, speed, request.

3. Proper clip pack

Record or generate dedicated aviation-English clips with global voices, add the MP3s to the repo, and import the manifest.

Best long-term setup

Use GLOBE for accent tolerance, then use a custom local clip pack for the actual ATC-style listening test. That gives reliable playback, known answer keys, and repeatable practice without exposing API keys.
